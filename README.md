# synthesizer-si5351-lcd-display
Синтезатор широкого спектра частот 10 килогерц до 100 мегагерц, доработка прошивки для использования lcd дисплея

Параметр promezh задает промежуточную частоту устройства, при синтезе частоты меньшей чем промежуточная частоты складываются, иначе - вычитаются
Нажатие на энкодер меняет текущий изменяемый разряд, изменяемый разряд подсвечивается на дисплее

Синтезатор опробован в трансивере "радио-76м2" и "Роса", работает стабильно, уровень выходного сигнала около 1 вольта
